# 할일 + 계획 관리 앱 PRD

## 1. why - 목적

- 일일 할 일을 단순 기록하는 수준을 넘어 주간 계획과 1년 목표까지 연결
- 사용자가 현재 해야 할 일과 장기 목표 간 관계를 확인 가능하도록 구성
- 할 일 상태를 `todo / doing / done`으로 관리
- 주간 진행률과 연간 진행률을 각각 자동 집계
- 드래그 앤 드롭 기반 상태 변경으로 빠른 할 일 관리 제공

## 2. who - 타깃 사용자

- 일일 할 일을 체계적으로 관리하려는 사용자
- 주간 계획을 기준으로 업무를 관리하는 사용자
- 연간 목표와 실제 실행 항목을 연결해서 관리하려는 사용자
- 개인 생산성 및 목표 달성률을 확인하려는 사용자

## 3. User Flow

- 앱 진입
  - 오늘의 할 일 확인
  - `todo / doing / done` 상태별 목록 확인

- 1년 목표 생성
  - 목표명 입력
  - 목표 저장

- 주간 계획 생성
  - 주간 계획명 입력
  - 연결할 1년 목표 선택(선택 사항)
  - 주간 계획 저장

- 할 일 생성
  - 할 일명 입력
  - 날짜 선택
  - 연결할 주간 계획 선택(선택 사항 — 미선택 시 "미분류" 할 일로 생성)
  - 상태 기본값 `todo`
  - 저장

- 할 일 진행
  - `todo` → `doing`
  - `doing` → `done`
  - 드래그 앤 드롭으로 상태 변경

- 할 일 수정
  - 할 일 선택
  - 내용 수정
  - 날짜 변경
  - 주간 계획 연결 변경(연결 해제도 가능)
  - 상태 변경
  - 저장

- 할 일 삭제
  - 할 일 선택
  - 삭제
  - 주간 진행률 재계산
  - 연간 진행률 재계산

- 주간 계획 확인
  - 연결된 할 일 목록 확인
  - 완료된 할 일 기준 주간 진행률 자동 계산
  - 연결된 1년 목표 확인

- 주간 계획 삭제
  - 주간 계획 선택
  - 삭제 방식 선택: ① 연결된 할 일 함께 삭제 / ② 할 일은 유지하고 "미분류"로 이동
  - 연결된 1년 목표의 연간 진행률 재계산

- 1년 목표 확인
  - 연결된 주간 계획 목록 확인
  - 각 주간 계획 진행률 확인
  - 연간 진행률 확인

- 1년 목표 삭제
  - 1년 목표 선택
  - 삭제 방식 선택: ① 연결된 주간 계획(및 하위 할 일) 함께 삭제 / ② 주간 계획은 유지하고 "미분류"로 이동

## 4. 기능 요구 사항

### P0 - 핵심 기능

- 할 일 CRUD
  - 생성
  - 조회
  - 수정
  - 삭제

- 할 일 데이터
  - `id`
  - 제목
  - 날짜
  - 상태
  - 연결된 주간 계획 ID(nullable — 미연결 허용)
  - 생성일
  - 수정일

- 할 일 상태
  - `todo`
  - `doing`
  - `done`
  - 신규 할 일 기본값: `todo`

- 상태 변경
  - 상태 직접 변경
  - 드래그 앤 드롭으로 상태 변경
  - 드롭 완료 즉시 상태 저장

- 상태 보드
  - `todo` 컬럼
  - `doing` 컬럼
  - `done` 컬럼
  - 각 컬럼에 해당 상태의 할 일 표시

- 일일 구조
  - 날짜별 할 일 조회
  - 특정 날짜의 할 일 생성
  - 날짜 변경 가능

- 주간 계획 CRUD
  - 생성
  - 조회
  - 수정
  - 삭제

- 주간 계획 데이터
  - `id`
  - 제목
  - 주 시작일
  - 주 종료일
  - 연결된 1년 목표 ID(nullable — 미연결 허용)
  - 주간 진행률
  - 생성일
  - 수정일

- 1년 목표 CRUD
  - 생성
  - 조회
  - 수정
  - 삭제

- 1년 목표 데이터
  - `id`
  - 제목
  - 대상 연도
  - 연간 진행률
  - 생성일
  - 수정일

- 계층 구조
  - `할 일 → 주간 계획 → 1년 목표`
  - 할 일은 하나의 주간 계획과 연결 가능(미연결도 허용)
  - 주간 계획은 하나의 1년 목표와 연결 가능(미연결도 허용)
  - 주간 계획에서 연결된 할 일 조회
  - 1년 목표에서 연결된 주간 계획 조회

- 주간 진행률
  - 주간 계획에 연결된 할 일 기준 계산
  - 계산식
    - `주간 진행률 = done 할 일 수 / 전체 할 일 수 × 100`
  - 분모(전체 할 일 수) 기준: 해당 주간 계획에 연결된 할 일만 포함, 미연결(미분류) 할 일은 어떤 주간 진행률 계산에도 포함되지 않음
  - 할 일 상태 변경 시 자동 재계산
  - 할 일 생성/삭제 시 자동 재계산
  - 할 일의 주간 계획 연결 변경(미연결 ↔ 연결 포함) 시 기존/신규 주간 계획 모두 재계산
  - 연결된 할 일이 없을 경우 `0%`

- 연간 진행률
  - 1년 목표에 연결된 주간 계획 기준 계산
  - 계산식
    - `연간 진행률 = 연결된 주간 계획들의 (완료 할 일 수 합계) / 연결된 주간 계획들의 (전체 할 일 수 합계) × 100`
  - 주간 진행률 변경 시 자동 재계산
  - 주간 계획 생성/삭제 시 자동 재계산
  - 주간 계획의 1년 목표 연결 변경 시 기존/신규 1년 목표 모두 재계산
  - 연결된 주간 계획이 없을 경우 `0%`

- 진행률 계산 흐름
  - 할 일 상태 변경
  - → 해당 주간 계획의 주간 진행률 재계산
  - → 해당 1년 목표의 연간 진행률 재계산

- 데이터 관계
  - `AnnualGoal 1:N WeeklyPlan`
  - `WeeklyPlan 1:N Task`
  - `Task.status → WeeklyPlan.weeklyProgress`
  - `WeeklyPlan(하위 Task 합계) → AnnualGoal.annualProgress`

  - 완료 할 일 수

- 1년 목표 상세

  - 날짜순
  - 상태순
